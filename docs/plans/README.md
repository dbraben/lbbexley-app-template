# Plans

One plan per change, written before building, named with the date and the change, for example `2026-11-02-first-screen.md`. In Claude Code, plan mode saves plans here; in Copilot, the lbbexley-plan agent does.

Each plan follows the plan skill's template: the user need, the real words users will read, acceptance criteria someone can check, the files to change, the tests to add, the compliance documents to update, and risks. The person approves the plan before anything is built.

Plans start from the user stories in `../requirements.md`, and the service's overall design in `../architecture.md`.
