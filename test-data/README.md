# Test data

Fictional data only. Never copy, export or "anonymise" real records for testing.

Use the safe formats in the data-protection skill (`test-data.md`): example.com email addresses, Ofcom drama phone numbers, QQ National Insurance numbers, NHS numbers starting 999, and the payment provider's sandbox test cards. The standards check rejects anything that looks like real personal data.

Keep files small. If you need a lot of data, write a script here that generates it, and commit the script rather than the output.
